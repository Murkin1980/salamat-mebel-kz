# Salamat Mebel

Новая статическая версия сайта [salamat-mebel.kz](https://salamat-mebel.kz/) для публикации на GitHub Pages.

## Что улучшено

- Пересобрана структура страницы: первый экран, услуги, портфолио, процесс, FAQ и контакты.
- Добавлены SEO title/description, Open Graph и JSON-LD для локального мебельного бизнеса.
- Убрана зависимость от тяжелого Tilda runtime, сайт работает как обычный HTML/CSS/JS.
- Добавлены доступные alt-тексты, мобильное меню и быстрые CTA на звонок и WhatsApp.

## Публикация

Сайт не требует сборки. GitHub Pages можно включить из ветки `main`, папка `/root`.
